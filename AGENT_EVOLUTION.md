# AGENT_EVOLUTION.md — Agent Growth System

## 0. Core Philosophy

Agents are NOT static tools.

**They are:**
- evolving assets
- user-owned capabilities
- long-term progression drivers

---

## 1. Agent Lifecycle

---

### Stage 1: Basic Agent

- low skill
- high error
- cheap

---

### Stage 2: Improved Agent

- better output
- lower failure rate

---

### Stage 3: Specialized Agent

- strong in one domain
- weak elsewhere

---

### Stage 4: Elite Agent

- high consistency
- high cost

---

## 2. Agent Attributes

---

Each agent has:
- **skill_level** (0–100)
- **efficiency** (token usage)
- **error_rate** (0–1)
- **specialization**

---

## 3. Upgrade System

---

### Upgrade Methods:

---

### 3.1 Direct Upgrade

Spend currency:

```formula
skill_level += X
error_rate -= Y
```

---

### 3.2 Usage-Based Growth

Agents improve with usage:

```formula
after N runs: skill +1
```

---

### 3.3 Specialization Unlock

Example:
- "Email Expert"
- "Ad Copy Expert"

---

## 4. Training System (Future)

---

Users can:
- refine prompts
- adjust personality

---

## 5. Agent Personality Tuning

---

**Adjustable parameters:**
- laziness
- creativity
- accuracy

---

**Trade-offs:**
- more creativity → more risk
- more accuracy → less originality

---

## 6. Agent Loadout (IMPORTANT)

---

Users select:
- 2–3 agents per workflow

---

**Goal:**
- create team composition strategy

---

## 7. Agent Synergy

---

Example:
- Researcher + Writer → better output
- Bad combo → worse results

---

## 8. Cost vs Performance Tradeoff

---

Better agents:
- cost more
- produce better outputs

---

Forces decision:
- optimize cost vs quality

---

## 9. Agent Market (Future)

---

Users can:
- sell trained agents
- share configurations

---

## 10. Progression Loop

---

```
Use agents → Earn profit → Upgrade agents → Improve results
```

---

## 11. Anti-Patterns

---

**DO NOT:**
- allow perfect agents
- remove failure entirely
- make upgrades too fast

---

## 12. Long-Term Retention

---

Players stay because:
- they build "their team"
- they improve over time

---

## 13. MVP Scope

---

Only implement:
- basic stats
- simple upgrade
- no training yet
